# Security Policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report them privately through GitHub: open the [Security tab](https://github.com/sleepwalkerffs/Clubnetz/security) of this repository and choose **Report a vulnerability**. Only the maintainers can see the report.

Please include:

- what the problem is and what an attacker could do with it
- the steps to reproduce it
- the affected version or commit

Don't include personal data of real club members. Use made-up data to demonstrate the problem.

You can expect a first answer within a week. Please give us the time to fix the problem before you publish any details.

## Supported versions

Only the latest version on the `master` branch receives security fixes.
