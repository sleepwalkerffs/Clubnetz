# Agents in .claude/agents

Subagents Claude can hand work to, locally and in the `Claude agent` GitHub workflow.

They are taken unchanged from [agency-agents](https://github.com/msitarzewski/agency-agents)
(MIT, Copyright (c) 2025 AgentLand Contributors, see [LICENSE-agency-agents](LICENSE-agency-agents)).
Only agents that fit Clubnetz are copied. Every agent's description is part of Claude's context,
so add new ones only when they are needed.
